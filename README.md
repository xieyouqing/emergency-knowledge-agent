# 应急助手 · 老人应急知识问答

给不会用智能手机的老人用的应急问答工具。出事时**按住说一句话**，系统判断场景、给出三段式步骤卡、并**直接念出来**。

不是通用聊天机器人。它只答知识库里有的应急与安全常识，**不会自己编操作步骤**——库外问题一律拒答，只给拨号按钮。

## 快速开始

**前置**：Node.js ≥ 18（本机实测 v22）、一个 DeepSeek API key（`.env` 是唯一存放位置，绝不进前端）。

### 1. 准备配置

```bash
cp .env.example .env
# 编辑 .env，填入 DEEPSEEK_API_KEY=sk-...
```

`.env` 已被 `.gitignore` 排除。**key 只在这一处**，前端通过本地代理调用，F12 看不到。

> **部署到公网前必须做的一件事**：代理的 CORS 来源默认是 `*`（任何网页都能调它）。
> 本地开发因为只监听 `127.0.0.1`，外部访问不到，所以可接受；
> 一旦放到公网服务器（M3 云端中继），**必须设 `LLM_PROXY_ORIGIN` 为具体来源**，
> 否则等于把 key 借给任何知道你地址的人用。

### 2. 起本地代理

```bash
node tools/llm_proxy.mjs        # 默认 127.0.0.1:8787
```

它同时承担四件事：意图判定转发、ASR 转发、日志落盘、**持有 API key**。
只监听回环地址，同网段其他人拿不到你的 key。

验证：

```bash
curl -s http://127.0.0.1:8787/health
# → {"ok":true,"model":"deepseek-chat","key_present":true,"ready":9,...}
```

### 3. 起静态服务并打开页面

**必须用 `localhost` 或 `https`，不能双击 `index.html`**——麦克风权限要求安全上下文。

```bash
cd app && python -m http.server 8899
```

然后打开 `http://localhost:8899/index.html`。

> 手机上想测？用局域网 IP 可以验界面与拨号，但**语音输入一定不行**
> （`http://192.168.x.x` 不是安全上下文，`getUserMedia` 拿不到麦克风）。
> 手机上要真验语音只有 https 一条路，属于 M3 的云端中继。

## 用法

| 做什么 | 怎么做 |
|---|---|
| 出事求助 | 按住「按住说话」说「煤气漏了」，松手 → 文字进输入框 → 卡片直接出现并朗读 |
| 查预防知识 | 打字问「怎么预防燃气泄漏」→ 出日常解释卡，自动念名称 + 一句结论 |
| 不方便说话 | 点图标（燃气泄漏、老人跌倒…）→ 出卡片 |
| 重听 / 停 | 卡片上有「再听一遍」「停止」 |
| 调语速 | 页面底部「慢一点 / 正常」，选中后记住 |
| 打电话 | 生命危险场景有拨号按钮，点了直接唤起拨号盘 |
| 不认识步骤 | 点一下步骤会出现 ✓ 打勾 |

**紧急模式一旦进入就锁定**，不能手动切回——防止老人在出事时误操作退出。

## 已知边界（不藏）

这些是**已知且被接受**的限制，不是待修的 bug：

| # | 限制 | 原因 | 处置 |
|---|---|---|---|
| 1 | **Android 浏览器完全没有朗读** | 真机实测：`speechSynthesis` 不存在（非微信、http 页） | 界面给出明确提示，不静默失败。Android 语音只剩 M3 的 APK 原生 TTS |
| 2 | **手机端语音输入不可用** | 需安全上下文（https），`http://192.168.x.x` 拿不到麦克风 | M3 云端中继解决 |
| 3 | **没有多轮对话记忆** | `messages` 只有单条 user，不带历史。老人分两次说会断 | 已登记 P12，排在后续版本 |
| 4 | **首句播报只是临界达标** | 最大 2629ms，判据 3000ms，余量 371ms | 波动来自判定段。若真机超 3 秒，改「先播已确定的场景名与号码」 |
| 5 | **判定结果会抖** | 同一句 `temperature:0` 连测 8 次，confidence 在 0.55 / 0.72 间跳 | 断言改成「落在安全集合内」而非确定值；解释见 `docs/09` §2.10.1 |
| 6 | **知识库只有 9 条** | `drowning`（溺水）阻塞在源文核对 | 库外问题一律拒答，不会编 |
| 7 | **离线只保证能听，不保证能说** | 离线 ASR 走讯飞 AIKit，需商务授权 + Rust FFI | 三条前置任一不满足即回退「图标区 + 手写」，不阻塞交付 |

此外：嘈杂环境识别率、方言口音两项**未测**，因此不许对外宣称「嘈杂环境也能用」「支持方言」。
样本全是安静环境 + 标准普通话（`docs/04` §7.1）。

## 几条设计约束（改代码前先看）

1. **不编。** 库外问题零步骤输出，只给拒答话术 + 拨号按钮。模型只输出标签（`intent` / `scene` / `confidence`），**不生成任何操作内容**。
2. **朗读稿只拼接，不改写。** 剥掉条目字段后必须只剩标点（S1）。唯一例外是生命危险场景末尾的「同时拨打 N」——那是「怎么说」不是「说什么」。
3. **不许静默失败。** 语音不可用、麦克风打不开、识别为空，每一种都要给出用户能看懂的原因。**不许把多种失败合并成一句「识别失败」**——老人无法据此做任何事。
4. **API key 绝不出现在前端、日志、响应里。** 日志侧脱敏两次（前端一次、代理收到再脱一次）。
5. **`app/knowledge.js` 是构建产物**，由 `tools/build_knowledge_js.py` 生成，不要手改。
