# PPT 素材包（2026-11-22）

来源：`https://anban-emergency-assistant.app.workbuddy.host/?sharecode=WH2RTIZXZI`
采集：Playwright + Edge，1440×900 桌面、390×844 手机，2x 缩放。

## 文件与用途

| 文件 | 内容 | 用在 PPT 哪页 |
|---|---|---|
| `01-首屏-桌面.png` | 桌面首屏：安伴/小安、按住说话、4 个场景 | 第 5 页（交互） |
| `02-日常科普卡.png` | 日常卡完整卡：结论/原因/预防/误区/朗读 | 第 5 页（双模式） |
| `03-紧急分诊卡.png` | 火灾/燃气首屏分诊：先问位置/味道 | 第 5 页（现场处置） |
| `04-紧急步骤卡.png` | 三段式步骤：立刻做/接着做/绝对不要做 + 拨 119 | 第 5 页（现场处置） |
| `05-审计视图.png` | 审计视图全屏：左侧老人视图 + 右侧决策链 | 第 4 页（AI 调度） |
| `05-审计视图-面板.png` | 审计面板单独裁图：识别/场景/动作/来源/S5 | 第 4 页（可替代全屏） |
| `06-首屏-手机.png` | 手机首屏，展示适老化布局 | 备用/封底 |
| `07-路由逻辑图.png` | 受控自主循环图：模型选工具 → 前置门 → 执行 → 回灌 | 第 4 页（必须） |
| `07-路由逻辑图.svg` | 同上矢量版，PPT 可直接导入 | 第 4 页（必须） |

## 使用建议

- 第 4 页：左侧放 `07-路由逻辑图.png`，右侧放 `05-审计视图-面板.png`（或全屏审计图）
- 第 5 页：日常卡 + 紧急步骤卡并排；分诊卡作为小图或备用
- 第 1 页：可用 `06-首屏-手机.png` 做手机 mockup
- 不要把所有图堆在一页；Demo 已经演过操作，PPT 只放“证据”

## 重新采集

```bash
# 需要 playwright（本地已 --no-save 安装）
node tools/capture_ppt_assets.mjs
```

如果线上链接更新了，先重新采集；`05-审计视图` 需要线上版本包含审计按钮。
